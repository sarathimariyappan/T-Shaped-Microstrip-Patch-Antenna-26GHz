# 📡 T-Shaped Microstrip Patch Antenna (26 GHz)

## 🔍 Project Overview

This project focuses on the design and analysis of a **T-shaped microstrip patch antenna** operating at **26 GHz** for radar communication applications.

The antenna is designed using **ANSYS HFSS** and optimized for improved impedance matching, radiation characteristics, and compact size.

---

## ⚡ Key Features

* Operates at **26 GHz (K-band)**
* **T-shaped patch design** for improved performance
* **Defected Ground Structure (DGS)** for better impedance matching
* Compact and high-frequency antenna design
* Suitable for **automotive radar & mmWave communication**

---

## 🧠 Technologies Used

* Electromagnetic Theory
* RF & Microwave Engineering
* ANSYS HFSS Simulation
* Microstrip Antenna Design

---

## 📐 Design Parameters

* Substrate: **Rogers RO4003**
* Dielectric Constant: **3.55**
* Frequency: **26 GHz**
* Patch Width: **3.82 mm**
* Patch Length: **2.11 mm**

---

## 📊 Results

* Return Loss (S11): **~ -30 dB**
* VSWR: **~ 1.06**
* Gain: **~ 5 dB**
* Directional Radiation Pattern

---

## 📈 Performance Highlights

* Excellent impedance matching
* Low reflection losses
* Stable directional radiation
* Compact antenna structure
